# جمعية 🎬

لعبة كوتشينة مصرية سينمائية — تجمع ممثلين وأفلام ومسلسلات وكروت كوماند، وأول واحد يعمل 4 جمعيات (تقدر تغيّرها) يكسب.

## قواعد اللعبة

- كل لاعب بيبدأ بـ 5 ورقات. في الأرض كومتين: **(ا)** الكومة الأساسية (كل الكروت)، و**(ب)** كومة الرمي (فيها ورقة واحدة في الأول).
- في دورك: **اسحب ورقة واحدة** من (ا) أو (ب) (إنت اللي بتختار)، وبعدها **ارمي ورقة** من إيدك على (ب). أي ورق بيترمي بيروح على (ب).
- **الجمعية:** قبل ما تسحب، اختار 3 ورقات واعرضهم على صحابك. كل اللاعبين التانيين بيشوفوا الـ 3 ورقات على شاشاتهم ويدوسوا موافق أو رفض:
  - الكل وافق ← الـ 3 ورقات بيترموا على (ب)، الجمعية بتتحسب، بتسحب 3 غيرهم، وبعدها **بتلعب دورك الأساسي عادي** (سحب ورقة + رمي ورقة).
  - أي حد رفض ← الجمعية مش بتتحسب، الورقات بتفضل في إيدك، وبتكمل دورك عادي.
  - في محاولة جمعية واحدة بس في الدور الواحد. صاحب الجمعية يقدر يلغيها لو حد وقف.
- شرط الفوز: **4 جمعيات** — ثابت `WIN_JAM3EYAT` في `src/gameLogic.js`.
- "هاجي معاكو كدا" لما تترمى (سواء وحدها أو ضمن جمعية) بتاخد كارت عشوائي من اللاعب اللي جاي بعدك في الدور.
- "بس يا بابا" بتعمل سكيب للاعب اللي جاي بعدك في الدور (مش أي حد).
- أول ما الكومة (ا) تخلص، كل كروت (ب) بتتخلط عشوائي وتبقى هي كومة (ا)، وكومة (ب) بتفضى ونكمل لعب.
- "نفض ورقك": اللاعب المنفوض بيرمي إيده كلها على (ب) وبيسحب 5 جداد من (ا).
- مفيش تسجيل دخول (auth) — أي حد معاه كود/لينك الروم يقدر يدخل يلعب.

## التشغيل محليًا

```bash
npm install
npm run dev
```

## قبل الرفع: لازم تعمل مشروع Firebase (مجاني)

اللعبة محتاجة سيرفر يزامن الحالة بين اللاعبين لحظيًا. استخدمنا **Firebase Firestore** لأنه مجاني وسهل مع Vercel (اللعبة نفسها static وبتتكلم مع Firebase مباشرة من المتصفح).

1. روح [console.firebase.google.com](https://console.firebase.google.com) واعمل مشروع جديد (مجاني).
2. من القائمة الجانبية: **Build > Firestore Database > Create database** — اختار وضع **Production**.
3. روح تبويب **Rules** والصق فيه محتوى ملف `firestore.rules` الموجود في المشروع ده، وانشره (Publish).
4. من **Project settings** (الترس ⚙️) > **General** > انزل لـ **Your apps** > دوس على أيقونة الويب `</>` واعمل تسجيل تطبيق.
5. هيديك object اسمه `firebaseConfig` — انسخه.
6. افتح ملف `src/firebase.js` عندك والصق فيه القيم بدل الـ placeholders.

## الرفع على Vercel

```bash
npm i -g vercel   # لو مش مثبت عندك
vercel
```

أو من خلال الموقع: اعمل import للمشروع من GitHub (ارفعه على ريبو الأول)، Vercel هيكتشف إنه Vite تلقائيًا. خطوة الـ Build: `npm run build`، ومجلد الإخراج: `dist`.

**مهم:** متنساش تحط قيم `firebaseConfig` في `src/firebase.js` *قبل* ما تعمل build/deploy.

## إزاي تلعب

1. حد من الجروب يدوس "اعمل روم" ويكتب اسمه → هياخد كود من 5 حروف/أرقام.
2. يبعت الكود أو لينك الدعوة (فيه زرار نسخ جاهز) لصحابه.
3. الباقي يدوسوا "انضم لروم" ويكتبوا الكود.
4. المضيف يدوس "ابدأ اللعبة" لما الكل يكون دخل.
5. في دورك: اسحب من (ا) أو (ب)، وبعدين اختار ورقة وارمِها. أو قبل السحب اختار 3 كروت واعرضهم كـ "جمعية" على صحابك.

استمتعوا! 🍿
